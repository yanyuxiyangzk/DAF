# Docs

Mermaid source diagrams for the product architecture and interactions.

Render locally with mermaid-cli:

```bash
npm i -g @mermaid-js/mermaid-cli
mmdc -i product-diagram.mmd -o product-diagram.svg
mmdc -i user-flow.mmd -o user-flow.svg
mmdc -i interaction-diagram.mmd -o interaction-diagram.svg
```

Or use VSCode Mermaid extension to preview `.mmd` files.
